# OriginLayer

OriginLayer is a decentralized media and file infrastructure platform built with Next.js.

## Features

- Drag & drop uploads
- Video, audio, image and document support
- Wallet connection with MetaMask
- Public share links
- Modern decentralized-style UI

## Stack

- Next.js
- React
- Tailwind CSS
- Ethers.js
- React Dropzone
